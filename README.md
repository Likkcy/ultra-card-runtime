# UCR Prototype 0.11 — 基础卡池完整批次 / 五英雄优化

基于 Prototype 0.10 继续完成第一轮“可构筑基础生态”，本版不扩新英雄，重点是让五个现有英雄都能用更完整的中立工具与职业组件真正组出一副正常牌。

## 0.11 重点

- 可收藏卡池：336 张。
- 中立牌：185 张；覆盖正常曲线、守护、防御、回能、检索、墓地、沉默/净化、事件/陷阱/装备反制、硬解与常规单位。
- 新增 39 张中立牌，新增 20 张五英雄补强牌。
- 新规则能力：沉默、净化、洗回牌库、最低/最高费用检索、墓地回收、低费复活、摧毁敌方陷阱/事件、攻击力设定等。
- 迪迦：补 GUTS 守护单位、形态适应工具、GUTS 墓地回收与形态回能；强力型/空中型直接转换牌也得到收益强化。
- 贝利亚：补黑暗守护、吸血式回复、自伤后的过牌与怪兽回收；英雄能力强化为 2 费打 3、自伤 1。
- 奈克瑟斯：补夜袭队守护、低血恢复、生命换技能节奏与逆境过牌；测试牌组重新加入诺亚觉醒终局。
- 雷欧：补 MAC 守护、格斗定向检索、受击恢复反打与沉默破防；测试牌组加入更完整的中后期格斗终结。
- 托雷基亚：默认牌组进一步从“陷阱堆”转成陷阱控制：仅保留 6 张核心陷阱，加入正常前排、主动解场、沉默和异次元硬解。
- AI 从“优先打最贵的牌”升级为基础启发式：会考虑血量、自伤风险、守护、治疗、抽牌、解场、场面威胁与职业协同。
- 0.10 及更早开发存档首次载入 0.11 时，会刷新为 0.11 的五套测试牌组，收藏仍自动补齐全部测试卡。

## 当前定位

仍是离线浏览器原型。美术素材、音效、联网、正式经济系统尚未完成；0.11 的目标是形成第一轮足够完整的“战斗与构筑卡池”，便于后续集中做实战平衡与视觉升级。
